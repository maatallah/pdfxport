# 1. 🧠 System Overview

PDFXport is a **3-layer document automation pipeline** designed to capture, transport, and process PDFs generated by a web application.

It currently operates in **Phase 1 (browser-assisted capture)** with a transition toward **Phase 2 (no-browser API orchestration)**.

***

## 🧩 High-level architecture

```
[Web Application]
      ↓
[Chrome Extension]
  - intercept XHR / fetch / blob PDFs
  - extract binary PDF
      ↓
[Background Service Worker]
  - receives Base64 payload
  - reconstructs PDF Blob
      ↓
[Go Server (port 8765)]
  - receives PDF via HTTP POST
  - stores or forwards for parsing
      ↓
[PDF Parser System]
  - extracts structured data
  - stores results in backend DB
```

# 3. ⚙️ Current Implementation Status (Phase 1)

## ✅ Working components

### Browser extension

* Intercepts:

  * XHR PDF responses
  * fetch-based PDFs
  * blob-based PDF generation

* Deduplicates identical blobs

* Converts PDF → Base64

* Sends via `chrome.runtime.sendMessage`

***

### Background service worker (MV3)

* Receives Base64 payload
* Reconstructs binary PDF
* Sends via HTTP POST to Go server

***

### Go server

* Listening on:

```
http://localhost:8765/upload
```

* Accepts raw PDF binary stream
* Saves file to disk / forwards to parser

***

# 4. 🔄 Data Flow (actual implemented)

```
1. Web app triggers PDF generation
2. XHR/fetch returns PDF blob
3. inject_xhr / inject_fetch captures response
4. inject_blob emits PDF_BLOB event
5. content_main.js:
   → converts Blob → ArrayBuffer → Base64
6. background.js:
   → decodes Base64 → Blob
7. POST → Go server (8765)
8. PDF stored / processed
```

***

# 5. ⚠️ Known Constraints / Design Decisions

## MV3 Messaging Limitation

* Direct Blob/ArrayBuffer transfer is unreliable
* Solution: Base64 encoding layer

***

## Duplicate generation

* Same PDF may be captured multiple times
* Mitigated via:

```
size + type hashing
```

***

## Port dependency

* Go server is fixed at:

```
8765
```

***

## UI dependency (still present)

* System currently depends on browser execution
* This is temporary (Phase 2 removes it)

## ⚙️ `internal/engine/batch.go`

This is the **core orchestrator loop**

```
package engine

import (
    "log"
    "pdfxport-orchestrator/internal/client"
    "pdfxport-orchestrator/internal/storage"
)

type Engine struct {
    client *client.SievalClient
    store  *storage.FileStore
}

func New() *Engine {
    return &Engine{
        client: client.New(),
        store:  storage.New("./output"),
    }
}

func (e *Engine) Run() error {

    jobs := []map[string]interface{}{
        {
            "productionProjectId": 210576,
            "productionPolygonIds": []int{573286, 573287},
            "languageCode": "fr",
        },
    }

    for i, job := range jobs {

        log.Printf("📄 Job %d started", i)

        pdf, err := e.client.GeneratePDF(job)
        if err != nil {
            return err
        }

        filename := e.store.SavePDF(pdf, i)

        log.Printf("✅ Saved: %s", filename)
    }

    return nil
}
```

## 🌐 `internal/client/sieval.go`

```
package client

import (
    "bytes"
    "io"
    "net/http"
)

const endpoint = "https://sievalhub.sieval.com/api/productiondata/document/generatePdfDocument"

type SievalClient struct {
    Token string
}

func New() *SievalClient {
    return &SievalClient{
        Token: "PUT_JWT_HERE",
    }
}

func (c *SievalClient) GeneratePDF(payload map[string]interface{}) ([]byte, error) {

    jsonBody, _ := toJSON(payload)

    req, _ := http.NewRequest("POST", endpoint, bytes.NewBuffer(jsonBody))
    req.Header.Set("Authorization", "Bearer "+c.Token)
    req.Header.Set("Content-Type", "application/json")

    resp, err := http.DefaultClient.Do(req)
    if err != nil {
        return nil, err
    }
    defer resp.Body.Close()

    return io.ReadAll(resp.Body)
}

// helper
func toJSON(v interface{}) ([]byte, error) {
    return json.Marshal(v)
}
```

## 💾 `internal/storage/file_store.go`

```
package storage

import (
    "fmt"
    "os"
)

type FileStore struct {
    basePath string
}

func New(path string) *FileStore {
    os.MkdirAll(path, 0755)
    return &FileStore{basePath: path}
}

func (s *FileStore) SavePDF(data []byte, index int) string {

    filename := fmt.Sprintf("pdf_%d.pdf", index)
    full := s.basePath + "/" + filename

    _ = os.WriteFile(full, data, 0644)

    return full
}
```
